# Pages demonstration

The Pages demo provides interactive controls for **subject**, **background**, **material**, **style**, and **animation**. It demonstrates the architecture rather than a catalog of hardcoded cat/boat/kite transformations.

### Acceptance
- Canvas always fits viewport on mobile.
- Every option repaints immediately.
- Environments are configurable independently of foreground subjects.
- All five styles visibly differ.
- Material choices visibly affect rendered treatment, not merely labels.
- Canvas is real; no static image fallback.
- Animation toggle freezes motion deterministically.

This is a procedural prototype with primitive scene geometry. It is not yet a general SVG ingestion/transformation workflow.
